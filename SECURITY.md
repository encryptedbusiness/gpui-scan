# Security policy

## Supported versions

`gpui-scan` is a development tool. Security fixes are applied to the latest `0.1.x` release.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| < 0.1 | No |

## Reporting a vulnerability

Please report security issues privately through GitHub's
[security advisory form](https://github.com/encryptedbusiness/gpui-scan/security/advisories/new),
or by email to `gautamsairash@gmail.com` if you cannot use GitHub.

Include the affected version, a minimal reproduction, and what an attacker could do with the issue.
You can expect an acknowledgement within a few days and a fix or mitigation plan in the next
patch release.

Please do not open a public issue for a vulnerability before it has been addressed.
